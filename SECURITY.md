# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please email security@bevelhook.com with all relevant details. Include the following information wherever possible:

1. Description of the vulnerability
2. Steps to reproduce the vulnerability
3. Potential impact or risk

We take security seriously, and we request you do not publicly disclose the vulnerability until we have addressed it. We aim to respond promptly and keep you informed of the resolution process.
